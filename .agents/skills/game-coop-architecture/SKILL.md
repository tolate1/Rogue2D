# Скилл "game-coop-architecture" — Внедрение кооператива в 2D Roguelike

Кооператив в 2D-рогалике строится в 2 последовательных этапа. Попытка сразу писать сложный онлайн-мультиплеер в игре, где физика и логика завязаны на один локальный объект `player`, разрушает проект. Ниже — безопасный путь.

---

## Этап 1. Локальный кооператив (Shared Screen / Couch Co-op)
**Самый быстрый и кайфовый способ начать играть вдвоем уже сейчас** (через клавиатуру + геймпад или два геймпада).

### Архитектурные шаги:
1. **Замена `self.player` на `self.players: list[Player]`**:
   - В цикле обновления враги (`Enemy.move_towards_player`) ищут **ближайшего живого игрока**:
     ```python
     def get_closest_player(self, players):
         alive = [p for p in players if p.is_alive]
         if not alive: return None
         return min(alive, key=lambda p: (p.rect.centerx - self.rect.centerx)**2 + (p.rect.centery - self.rect.centery)**2)
     ```
2. **Управление для двух игроков (Input Mapping)**:
   - Игрок 1: Клавиатура (WASD + Пробел/ЛКМ) или Геймпад 1.
   - Игрок 2: Стрелочки (NumPad) или Геймпад 2 (`pygame.joystick.Joystick(0)` и `Joystick(1)`).
3. **Общая динамическая камера (Bounding Box Camera)**:
   - Камера держит центр между обоими игроками:
     ```python
     cam_x = (player1.x + player2.x) / 2
     cam_y = (player1.y + player2.y) / 2
     ```
   - Если один игрок уходит к краю экрана, он не может выйти за пределы видимой зоны, пока напарник не догонит.
4. **Возрождение (Revive Mechanic)**:
   - Когда один погибает, он переходит в состояние «призрак/нокаут». Напарник может постоять рядом 3 секунды, чтобы поднять его с 30% HP. Если погибли оба — Game Over.

## Этап 2. Сетевой кооператив по интернету (Online Co-op)

Для игры с другом по сети есть два пути:

### Путь А. Бесплатный и нулевой по затратам кода — Steam Remote Play / Parsec
- Вы делаете **Этап 1 (Локальный кооператив)**.
- Друг подключается к вашему ПК через **Parsec** или **Steam Remote Play Together** (транслируется экран с нулевой задержкой, друг со своего геймпада/клавиатуры управляет вторым игроком).
- **Результат**: Ни строчки сложного сетевого кода, синхронизация кадров 100%, игра готова к совместной игре за пару дней!

### Путь Б. Настоящий сетевой мультиплеер (Архитектура Client-Server)
Если писать чистый сетевой код на Python:
1. **Библиотеки**: `asyncio` + `websockets` или легкий UDP-сокет.
2. **Паттерн Host & Client**:
   - Один игрок — Хост (Server + Player 1). Он генерирует сид подземелья, считает спавн врагов, коллизии и здоровье.
   - Второй игрок — Клиент (Player 2). Только отправляет свои нажатия кнопок (Input) и принимает от хоста список позиций `(x, y, anim_state)` всех видимых сущностей.
   - Это исключает рассинхронизацию комнат и предметов.
