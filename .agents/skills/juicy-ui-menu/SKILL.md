# Скилл "juicy-ui-menu" — Архитектура и эстетика UI для Rogue2

Этот скилл содержит стандарты оформления, математику плавных анимаций и структуру компонентов интерфейса (Главное меню, Настройки, HUD, Сетки инвентаря), чтобы UI выглядел как в коммерческих инди-играх (Hades, Stoneshard, Loop Hero).

---

## 1. Анатомия "Сочного" Главного Меню (Main Menu Feel)

### 1.1. Живой фон (Breathing Background & Parallax)
- **Параллакс от мыши**: Смещение фоновых слоев пропорционально положению курсора относительно центра экрана:
  ```python
  offset_x = (mouse_x - SCREEN_WIDTH / 2) * factor  # factor = 0.02 для дальнего плана, 0.05 для ближнего
  ```
- **Плавающие частицы (Atmospheric Embers / Ash)**:
  - 25-40 частиц с разной альфой (от 60 до 180), плавно плывущих снизу вверх с горизонтальным синусоидальным покачиванием `math.sin(time + seed)`.
  - Теплые оранжево-пепельные или мрачно-бирюзовые тона.

### 1.2. Микроанимации кнопок (Hover & Click Physics)
Обычная смена цвета выглядит плоско. Кнопка должна ощущаться физическим объектом:
- **Плавный сдвиг (Lerp offset)**: При наведении кнопка плавно смещается вправо на 6-10 пикселей:
  ```python
  self.target_x = self.base_x + (8 if self.is_hovered else 0)
  self.current_x += (self.target_x - self.current_x) * 0.2  # плавное приближение
  ```
- **Маркер выбора**: Слева от текста плавно разгорается рунический маркер или острие `►` (с альфа-переходом).
- **Отклик на клик (Squash / Punch)**: При нажатии кнопка смещается на 2 пикселя вниз и уменьшается на 3% по высоте на 3 кадра, после чего срабатывает звук глухого деревянного или каменного щелчка.

## 2. Экран Настроек (Settings Modal & Grid Alignment)

### 2.1. Железное правило верстки (Никаких вылетов за рамки!)
- **Центрированная подложка (Darkened Panel)**:
  - Затемнение заднего плана полупрозрачным черным `(0, 0, 0, 160)`.
  - Каменная или темная дубовая панель с двойной каймой (внешняя темная, внутренняя золотисто-бронзовая полоска 1px).
- **Табличная верстка (2 колонки)**:
  - **Колонка A (Название параметра)**: выравнивание по левому краю с отступом (например `x = panel_left + 40px`).
  - **Колонка B (Контрол / Значение)**: фиксированная ширина (например, `220px`), центрированная внутри правой половины панели.
  - Текст вроде `Toggle Display Mode` не должен задавать ширину кнопки на глаз! Кнопка имеет фиксированный размер, а размер шрифта адаптируется или сокращается (`Display: Fullscreen / Windowed`).

## 3. HUD и Инвентарь (Dark Fantasy RPG Style)

### 3.1. Панель способностей (Skill Bar)
- Каждая ячейка — квадрат со скругленной или резной рамкой 48x48 пикселей.
- **Векторные / четкие силуэты**: Иконки берутся в высоком разрешении (SVG/PNG из Game-Icons) и масштабируются алгоритмом `pygame.transform.smoothscale`.
- **Кулдаун (Radial / Vertical Swipe)**: Полупрозрачная серая шторка, сползающая сверху вниз, и цифра секунд белым шрифтом с черной 1px обводкой в центре ячейки.

### 3.2. Сетка инвентаря и стаки предметов
- **Стакание одинаковых предметов**:
  - `Item` содержит поле `count: int`.
  - Одинаковые зелья/свитки объединяются до максимума (например, `max_stack = 20`).
  - Число пишется в правом нижнем углу слота мелким четким шрифтом (`x3`, `x12`) с контрастной черной тенью.
- **Приоритет в слотах быстрого доступа**:
  - Зелья лечения/маны всегда занимают первые 1-2 слота и активируются кликом ЛКМ или горячими клавишами `1`, `2` / `Q`, `E`.

---

## 4. Звуковой фидбек (Audio UX)
- Каждый тип действия имеет разный тембр:
  - Наведение на кнопку: едва слышный шелест/свист (hover).
  - Нажатие кнопки меню: плотный щелчок дерева/камня.
  - Подбор предмета: звон монет или глухой шорох сумки.
  - Питье зелья: характерный глоток и звон стеклянной склянки.
