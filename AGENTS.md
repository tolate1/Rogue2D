# Rogue2D — Правила и инструкции для ИИ-агента

## 1. Стек и окружение
- **Язык и библиотеки**: Python 3.11 + Pygame 2.6.1 + Pillow 10.4.0 (без сторонних тяжелых игровых движков).
- **Виртуальное окружение для разработки**: `.venv\`.
- **Запуск тестов**: `.venv\Scripts\python.exe -m unittest discover -s tests`
- **Запуск игры**: `run.bat` или `Rogue2.exe`; при установленном Python — `python main.py`.
- **Сборка Standalone EXE**: `.venv\Scripts\python.exe scripts\build_exe.py` (или `build_exe.bat`).

## 2. Железные правила разработки
1. **Прозрачность костылей и поиск готовых решений (Главный закон)**:
   - Запрещено скрывать или молча внедрять костыли и хаки. Если где-то используется временное решение, агент обязан **прямо сообщить об этом** с объяснением причин и рисков.
   - Вместо кустарных костылей агент обязан искать референсы, открытые репозитории, тайлсеты, шейдеры и датасеты в интернете (itch.io, GitHub, OpenGameArt, Game-Icons).
2. **Не переписывать файлы целиком**:
   - Вносить точечные, изолированные изменения.
   - Перед редактированием ознакомься с `docs/PROJECT_MAP.md`, чтобы точно знать, какой класс и метод отвечают за механику.
3. **Не добавлять зависимости без явного согласования**:
   - Используем стандартную библиотеку Python, Pygame и Pillow.
   - Для UI используем существующую реализацию в `src/ui.py`, не нагромождая внешние GUI-фреймворки.
4. **Не считать задачу выполненной без тестов**:
   - Любое изменение боевой системы, здоровья, инвентаря, генератора уровней должно сопровождаться или проверяться юнит-тестом.
   - Тесты запускаются в headless-режиме (`os.environ["SDL_VIDEODRIVER"] = "dummy"`).
5. **Защита от бесконечного урона за 1 кадр (Hit-box multi-hit)**:
   - При вводе здоровья врагов следить за кулдауном нанесения урона (i-frames / таймер удара), чтобы один взмах меча не снимал HP каждый фрейм.
6. **Сохранение целостности ресурсов**:
   - Пути к спрайтам загружаются исключительно через `load_image` из `src/utils.py`, поддерживающий авто-резолв путей и кэширование.

## 3. Скилл legacy (Накопленный опыт и референсы)
Всегда сверяйся с `.agents/skills/legacy/SKILL.md`. В нем зафиксированы:
- Проверенные репозитории и открытые базы ассетов (Game-Icons.net, 0x72, Kenney, pygame-shaders) вместо рисования примитивов кодом.
- Замечания тестировщика по UI, инвентарю, освещению и AI лучника.
- Правила предотвращения крашей при ударе по объектам и использовании скиллов.
- `.agents/skills/juicy-ui-menu/SKILL.md`: Архитектура сочного меню, параллакс, микроанимации кнопок (lerp offset/squash), 2-колоночные модалки настроек без вылетов текста, стакание инвентаря.
- `.agents/skills/game-coop-architecture/SKILL.md`: Пошаговый план внедрения кооператива (локальный общий экран через `self.players`, Input Mapping, Parsec/Steam Remote Play и Client-Server сокеты).
- `.agents/skills/game-lighting-vfx/SKILL.md`: Архитектура масок тьмы (BLEND_SUB/MULT), радиальные градиенты света, живое мерцание факелов (двойной sin), взрывные кольца (Shockwave) и летающие пылинки в свете.
- `docs/RTX_SHADERS_ROADMAP.md`: Дорожная карта внедрения GPU-шейдеров (`moderngl`, `pygame-shaders`), 2D RTX нормалей и физики `pymunk`.
