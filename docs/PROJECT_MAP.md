# Карта проекта Rogue2 (PROJECT_MAP.md)

Документ для быстрой навигации по кодовой базе. Используйте вместо повторного чтения сотен строк кода.

---

## 1. Точка входа и глобальный цикл
* **`main.py`**
  * `class Game`: Инициализация Pygame, создание окна (1280x720), глобальный Game Loop (`events`, `update`, `draw`).
  * **FSM (Состояния)**:
    * `'menu'` — Главное меню (кнопки Start, Settings, Exit, анимированные летучие мыши и факелы).
    * `'game'` — Основной геймплей (обновление `Level`, отрисовка мира и `UI`).
    * `'pause'` — Меню паузы по `ESC` (кнопки Resume, Settings, Menu).
    * `'settings'` / `'settings_ingame'` — Меню настроек (зум камеры, HUD scale, возврат).

## 2. Модули ядра (`src/`)

### `src/settings.py`
* Глобальные константы: `TITLE`, `WIDTH` (1280), `HEIGHT` (720), `FPS` (60), `TILE_SIZE` (64).
* Цветовые константы (RGB).

### `src/utils.py`
* `BASE_DIR`: Корневая директория проекта.
* `get_asset_path(path)`: Преобразует относительный путь ассета в абсолютный, гарантируя загрузку из любой рабочей директории.
* `load_image(path, scale=None)`: Кэшированная загрузка изображений с поддержкой альфа-канала (`convert_alpha`) и заглушкой при отсутствии файла.
* `import_folder(path)`: Пакетная загрузка спрайтов из папки.

### `src/map_manager.py`
* `class Tile(pygame.sprite.Sprite)`: Одиночный тайл стены или пола с поддержкой биомов и тинтов.
* `class Level`:
  * `create_map()`: Процедурная генерация уровня через алгоритм Random Walk (400 шагов), генерация стен вокруг пола.
  * Управление биомами: `'dungeon'`, `'forest'`, `'ice'`, `'volcano'`.
  * Спавн сущностей: игрок, враги (или босс на каждом 5-м этаже), сундуки (`Chest`), лестница вниз (`Stairs`), разрушаемые ящики/бочки (`Breakable`), торговец (`merchant`).
  * `update()`: Обновление спрайтов, проверка перехода на лестницу с сохранением статов игрока, открытие сундуков.
  * `render_fog()`: Радиальное освещение вокруг игрока (маска света 500px, режим `BLEND_RGBA_MIN`).
* `class CameraGroup(pygame.sprite.Group)`:
  * Камера с центрированием на игроке, отсечением невидимых объектов (culling) и масштабированием (zoom).
  * Z-сортировка: сначала пол, затем остальные объекты по координате Y (`centery`).
* `class Stairs`, `class Torch`: Интерактивные объекты уровня.

### `src/entities.py`
* `class Entity(pygame.sprite.Sprite)`:
  * Базовый класс для динамических объектов.
  * Физика: субпиксельные координаты `pos` (`pygame.math.Vector2`), ускорение, трение, скорость, коллизии с препятствиями по осям X и Y.
  * Анимация: покадровая смена спрайтов (`animate()`).
* `class Player(Entity)`:
  * Управление: WASD.
  * Атака: ЛКМ — взмах мечом в сторону курсора мыши ([`Weapon`]).
  * Скиллы:
    * **Z** — Рывок (Dash, ускорение на 200 мс с кулдауном).
    * **X** — Щит (Shield, открывается с 5 ур., 5 сек неуязвимости).
    * **C** — Ультимейт (AOE урон в радиусе 800px, открывается с 15 ур.).
  * Прокачка: `gain_exp()`, рост уровня, максимального HP и урона.
* `class Enemy(Entity)`:
  * Типы: `'skeleton'`, `'zombie'`, `'goblin'`, `'imp'`, `'lurker'`, `'yeti'`, `'bat'`, `'boss_void_knight_0'`.
  * AI: преследование игрока в радиусе агро, периодическая проверка видимости Line-of-Sight через препятствия.
  * Атака: ближний контакт или стрельба ([`EnemyProjectile`]).
* `class Weapon(pygame.sprite.Sprite)`:
  * Меч, создаваемый перед игроком с поворотом под углом к курсору.
  * Обработка попадания по врагам и разрушаемым ящикам.
* `class EnemyProjectile(pygame.sprite.Sprite)`:
  * Снаряд скелета/беса, летящий по направлению, сталкивающийся со стенами и игроком.

### `src/items.py`
* `class Item`: Модель предмета с редкостью (`common`, `rare`, `epic`, `legendary`), баффами статов и иконкой.
* `generate_random_item()`: Генератор мечей, брони, зелий, амулетов, сапог и перчаток.
* `class Chest`: Сундук с предметами.
* `class Breakable`: Разрушаемые бочки и коробки (`crate.png`, `barrel.png`), дропающие зелья или золото.
* `class Gold`: Выпадающие из врагов монеты, которые игрок притягивает/собирает.

### `src/ui.py`
* `class UI`:
  * Отрисовка полос здоровья (красная) и энергии (синяя).
  * Кэширование текстовых поверхностей статов (уровень, опыт, золото).
  * Отображение инвентаря с подсказками по наведению курсора (hover tooltip).
  * Debug-оверлей по `F3`.
* `class Button`: Универсальная кнопка интерфейса для меню и настроек с поддержкой hover и клика.

## 3. Набор тестов (`tests/`)
* `test_overlap.py`: Проверка отсутствия наложения лестниц, сундуков и препятствий при генерации.
* `test_rendering.py`: Проверка корректности порядка отрисовки (Z-sort: пол -> сущности по Y).
* `test_simulation.py`: Проверка физики движения игрока по WASD в headless-режиме.
* `test_spawning.py`: Проверка пула врагов для биомов (Dungeon и др.).
