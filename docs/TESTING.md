# Инструкция по тестированию (TESTING.md)

## 1. Среда выполнения
Для всех проверок используется локальное виртуальное окружение Python 3.11:
- Путь к интерпретатору: `.venv\Scripts\python.exe`
- Установленные пакеты: `pygame 2.6.1`, `pillow 10.4.0`

## 2. Команды запуска тестов

### Запуск всех тестов проекта
```powershell
& .venv\Scripts\python.exe -m unittest discover -s tests
```

### Запуск конкретного теста
```powershell
& .venv\Scripts\python.exe -m unittest tests/test_simulation.py
& .venv\Scripts\python.exe -m unittest tests/test_overlap.py
& .venv\Scripts\python.exe -m unittest tests/test_spawning.py
& .venv\Scripts\python.exe -m unittest tests/test_rendering.py
```

## 3. Headless-режим (Без графического окна)
Все тесты Pygame должны выполняться без открытия физического окна на экране. Для этого в начале тестового модуля задается фиктивный драйвер SDL:
```python
import os
os.environ["SDL_VIDEODRIVER"] = "dummy"
import pygame
pygame.init()
pygame.display.set_mode((100, 100))
```

## 4. Чек-лист проверки при разработке новых механик
Перед тем как объявить задачу завершенной:
- [ ] **Боевая система (Damage/HP)**:
  - Проверено, что удар меча наносит урон ровно один раз за взмах (нет мульти-хита за кадр).
  - При `HP <= 0` враг умирает ровно один раз, начисляя опыт и золото без дублирования.
- [ ] **Экран смерти (Game Over)**:
  - При `player.health <= 0` состояние игры корректно переключается в `'game_over'`.
  - При нажатии «Restart» сбрасываются статы, карта генерируется заново, игрок снова жив.
- [ ] **Инвентарь и зелья**:
  - При использовании зелья восстанавливается здоровье (не превышая `max_health`).
  - Использованное зелье удаляется из инвентаря.
- [ ] **Торговец (Merchant)**:
  - Проверено списание золота и появление купленного предмета в инвентаре.
  - Покупка не срабатывает при нехватке золота.
- [ ] **Регрессия**:
  - Все существующие тесты в `tests/` завершаются со статусом `OK`.
